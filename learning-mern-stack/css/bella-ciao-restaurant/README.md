# Bella Ciao Restaurant 🍽️

A Money Heist themed restaurant website built with pure HTML and CSS. Named after the iconic song from the series, the site uses a dark red and black color palette inspired by the show's aesthetic.

## Live Preview

> Open `index.html` in any browser to view the site.

## Theme

Inspired by the Netflix series **Money Heist (La Casa de Papel)**, the site uses:
- Dark black backgrounds (`#0a0a0a`, `#111`)
- Heist red accents (`#c0392b`, `#e74c3c`)
- City codenames for menu categories (Tokyo, Berlin, Nairobi, Moscow)
- Heist-themed section names and copy throughout

## Sections

| Section | Heist Name | Description |
|---------|------------|-------------|
| Home | The Vault | Hero landing section |
| Menu | The Loot | 4 category food menu |
| About | The Crew | Team cards + story |
| Contact | Radio In | Info + contact form |
| Reservation | Plan The Heist | Table booking form |
| Footer | — | Links, hours, socials |

## Features

- Fixed navbar with smooth scroll
- Hero section with CTA buttons
- 4 menu categories — Starters, Mains, Desserts, Drinks
- Crew cards with hover effects
- Contact form with validation
- Reservation form with date and time picker
- Footer with quick links and social links
- Hover animations throughout (translateY, border color)
- CSS-only responsive design — no JavaScript used

## Technologies Used

- HTML5
- CSS3 (Flexbox + Grid)
- No frameworks
- No JavaScript
- No external libraries
