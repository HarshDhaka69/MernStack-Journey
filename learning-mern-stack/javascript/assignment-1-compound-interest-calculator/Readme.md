# Compound Interest Calculator

A simple JavaScript program to calculate the final amount using the Compound Interest formula.

## Formula

A = P × (1 + R / N) ^ (N × T)

Where:

- A = Final Amount
- P = Principal Amount
- R = Rate of Interest
- N = Number of Times Interest is Compounded in a Year
- T = Time (Years)

## Technologies Used

- JavaScript

## How to Run

1. Open the `index.html` file in any browser.
2. Right-click anywhere on the page.
3. Click **Inspect**.
4. Open the **Console** tab to view the output.

## Example

**Input:**

- Principal: 20000
- Rate: 2%
- Time: 3 Years
- Compounded: 1 Time Per Year

**Output:**

```
Compound Interest After 3 Years Is : 21224.16
```
