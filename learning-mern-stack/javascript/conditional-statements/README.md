# Conditional Statements

Practice with JavaScript's conditional branching constructs.

## Concepts Covered
- `if`, `if...else`, nested `if`
- `else if` ladders
- `switch` (with strict `===` comparison)

## Files
- `if-else.js` — if/else/nested-if/else-if-ladder examples
- `switch.js` — switch-case example

## How to Run
Run either file with `node <file>.js`.
