# Even Odd Checker

A simple JavaScript program that checks whether a given number is even or odd using an `if-else` statement.

## How It Works

The program uses the modulus (`%`) operator to find the remainder after dividing a number by `2`.

- If the remainder is `0`, the number is **Even**.
- Otherwise, the number is **Odd**.

## Technologies Used

- JavaScript

## How to Run

1. Open the `index.html` file in any browser.
2. Right-click anywhere on the page.
3. Click **Inspect**.
4. Open the **Console** tab to view the output.

## Example

**Input:**

```text
10
```

**Output:**

```text
Number Is Even
```

**Input:**

```text
5
```

**Output:**

```text
Number Is Odd
```
