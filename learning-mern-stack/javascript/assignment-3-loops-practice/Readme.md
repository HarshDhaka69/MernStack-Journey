# JavaScript Loops Assignment

A beginner-friendly JavaScript assignment demonstrating the use of loops, conditional statements, and basic programming logic by solving common number-based problems.

## Features

- Print a Number
- Calculate the Sum of First N Numbers
- Calculate the Sum of Digits of a Number
- Check if a Number is Prime
- Check if a Number is an Armstrong Number
- Print All Factors of a Number
- Generate a Multiplication Table

## Concepts Used

- Variables (`const`, `let`)
- Arithmetic Operators
- Comparison Operators
- Conditional Statements (`if...else`)
- `for` Loop
- `while` Loop
- String Conversion (`toString()`)
- Type Conversion (`Number()`)

## How to Run

1. Open the `index.html` file in any browser.
2. Right-click anywhere on the page.
3. Click **Inspect**.
4. Open the **Console** tab to view the output.
