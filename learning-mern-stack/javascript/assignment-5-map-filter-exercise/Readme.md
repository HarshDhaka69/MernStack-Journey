# Map & Filter with HTML

This project demonstrates how to use JavaScript **map()** and **filter()** methods to dynamically display and search student records.

## Features

- Display student records as cards
- Search students by name
- Real-time search using the `input` event
- Dynamic HTML rendering using `map()`
- Filter students using `filter()`

## Technologies Used

- HTML
- CSS
- JavaScript (ES6)

## Concepts Covered

- Arrays of Objects
- Higher Order Array Methods
  - `map()`
  - `filter()`
- DOM Manipulation
- Event Listeners
- Template Literals
- Dynamic Rendering
