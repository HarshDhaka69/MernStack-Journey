# Callbacks, Promises & Error Handling

Practice with asynchronous JavaScript patterns and error handling.

## Concepts Covered
- Callback hell (deeply nested callbacks) and why it's hard to maintain
- Promises: `resolve()`, `reject()`, `.then()`, `.catch()`, `.finally()`
- Basic async error handling

## Files
- `callbackhell.js` — nested-callback example
- `promises.js` — Promise-based rewrite

## How to Run
Run with `node <file>.js`.
