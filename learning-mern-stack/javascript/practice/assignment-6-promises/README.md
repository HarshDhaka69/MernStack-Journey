# JavaScript Promise Division Assignment

This project demonstrates the use of JavaScript **Promises** to perform division between two numbers while handling errors such as division by zero.

## Objective

Create a JavaScript function that performs division using a Promise. The Promise resolves with the division result when the input is valid and rejects with an error message if the second number is zero.

## Features

- Accepts two numeric inputs
- Performs division using a Promise
- Rejects the Promise when dividing by zero
- Handles success using `.then()`
- Handles errors using `.catch()`
- Executes cleanup code using `.finally()`

## Concepts Covered

- Promises
- `resolve()`
- `reject()`
- `.then()`
- `.catch()`
- `.finally()`
- Error Handling
- User Input with `prompt()`
