# Array Higher-Order Methods

Practice with JavaScript's built-in higher-order array methods.

## Concepts Covered
- `map()` — transform every element into a new array
- `filter()` — keep elements matching a condition
- `find()` — return the first matching element
- `reduce()` — fold an array down to a single value

## How to Run
Open `script.js` in a browser console, or run `node script.js`.
