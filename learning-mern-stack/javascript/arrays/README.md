# Arrays

Practice with core JavaScript array operations.

## Concepts Covered
- Creating and printing arrays (including mixed-type elements)
- Accessing elements by index and reading `.length`
- Reference copying and its effect on the original array
- `indexOf()` and `includes()`
- `push()` and `unshift()`

## How to Run
Open `script.js` in a browser console, or run `node script.js`.
